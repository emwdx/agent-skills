# Day 2: Writing Your Script

## Goal
You will write down what you are going to say for your presentation using sentence frames.

## Preparation
*   Have your notes from Day 1 ready (the sentences you wrote about each slide).

## Instructions
Follow each step below. Mark the checkbox when you are done with that step.

1. Look at your first "main point" from Day 1.
   - [ ] Done

2. Write a script for this point using this frame:
   *I want to tell my audience about ___________________.*
   - [ ] Done

3. Look at your second "main point" from Day 1.
   - [ ] Done

4. Write a script for this point using this frame:
   *Another important part is ___________________.*
   - [ ] Done

5. Look at your third "main point" from Day 1.
   - [ ] Done

6. Write a script for this point using this frame:
   *The most exciting thing about the dog smelling station is ___________________.*
   - [ ] Done

7. Read your three scripts out loud to make sure you are happy with how they sound.
   - [ ] Done

## Finish Line
You are finished when you have written a script for each of your 3 main points and have read them out loud once.
