# Student Adaptations — Session Configuration

## Skills

Load the following skills at the start of every session:

- skills/student-context/SKILL.md
- skills/student-proficiency-scales/SKILL.md

## Session instructions

At the start of every session in this directory, read both skill files above.
Apply them to every piece of output generated in this session without being asked.
Before generating any material, check it against the student context file.
Every output is a markdown file for ultimately being pasted into Google Docs.

## Default assumptions

Unless a project brief specifies otherwise:
- Solo track — no group work, though interaction with other students to give/receive feedback is a good idea.
- Sixth-grade reading level
- Every task needs explicit steps, sentence frames, and a visible finish line
- No inferencing required at any point
- Output format is always a Markdown file, or a series of Markdown files if the output should be multiple documents.

## What good output looks like

Before finalizing any material, check:
- Every step does one thing only
- No step requires the student to infer an unstated expectation
- Every writing task has a sentence frame or fill-in structure
- Every checkpoint has a completion checklist
- The tone is direct and supportive — not clinical, not over-enthusiastic
