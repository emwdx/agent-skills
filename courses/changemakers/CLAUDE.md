# Changemakers Course

This directory contains skills and materials specific to the Changemakers course.

## Course Skills

Skills in `skills/` define the context, conventions, and style preferences that govern how an AI agent should assist with this course. Each skill is scoped to this course and supplements — but does not replace — the core skills in `core/`.

| Skill | Purpose |
|-------|---------|
| [course-context](skills/course-context/SKILL.md) | Background, goals, and student profile for the Changemakers course |
| [proficiency-scales](skills/proficiency-scales/SKILL.md) | Proficiency scale definitions used across Changemakers assessments |
| [rubric-style](skills/rubric-style/SKILL.md) | Voice, format, and descriptor conventions for Changemakers rubrics |
| [materials-style](skills/materials-style/SKILL.md) | Style and formatting conventions for Changemakers instructional materials |

## Projects

Course-specific projects live in `projects/`. Each project subdirectory contains its own materials, rubrics, and agent context.

## Session instructions

At the start of every session in this directory, read all four skill files listed above.
Apply them to every piece of output generated in this session without being asked.
Before generating any material, check it against the relevant skill files.
If a request conflicts with the course context or style conventions, flag it.

## Default assumptions

Unless a project brief specifies otherwise:
- Grade 10, international school, Santiago, Chile
- 80-minute class blocks
- Co-taught — use "we" and "your teachers", not "I"
- Competency-based assessment on a 2.0–4.0 scale
- Students often need support with scope, research depth, and meaningful collaboration
- Read the project brief.md before generating anything
